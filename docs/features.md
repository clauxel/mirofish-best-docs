# Features - MiroFish AI

MiroFish AI turns a question and evidence packet into a multi-agent scenario simulation with paths, confidence notes, and an exportable prediction report.

## Chat-style question intake

Ask the decision question in plain language, then attach evidence and constraints before the simulation begins.

## Evidence packet review

Keep sources, assumptions, and missing facts visible so a prediction can be inspected.

## Multi-agent simulation

Run separate simulated roles to pressure-test incentives, reactions, second-order effects, and timing.

## Scenario paths

Compare likely, optimistic, defensive, and contrarian paths instead of receiving one flat answer.

## Prediction report export

Create a structured report with confidence notes, evidence references, and recommended next actions.

## Decision-ready pricing path

Use the public pricing and checkout flow when teams need saved reports and repeat simulations.

## Pricing and Support

Plans cover scenario simulations, evidence packets, report exports, saved predictions, and team-oriented review support.
