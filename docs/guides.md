# Guides - MiroFish AI

MiroFish AI turns a question and evidence packet into a multi-agent scenario simulation with paths, confidence notes, and an exportable prediction report.

## Write a better MiroFish prompt

Name the decision, deadline, actors, evidence, uncertainty, and what kind of recommendation is useful.

## Build an evidence packet

Separate facts, assumptions, links, dated notes, and missing evidence before asking for a prediction.

## Read a prediction report

Focus on paths, confidence, evidence gaps, leading indicators, and actions that reduce regret.

## Pricing and Support

Plans cover scenario simulations, evidence packets, report exports, saved predictions, and team-oriented review support.
