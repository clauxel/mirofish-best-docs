# How It Works - MiroFish AI

MiroFish AI turns a question and evidence packet into a multi-agent scenario simulation with paths, confidence notes, and an exportable prediction report.

## Ask the prediction question

State the decision, target timeframe, audience, and what would count as a useful answer.

## Attach evidence

Add memos, links, data points, market notes, product facts, or policy context that should shape the simulation.

## Run the simulation room

Let separate roles test incentives, risks, adoption paths, objections, and timing.

## Export and review

Use the prediction report to compare confidence, evidence gaps, and concrete next moves.

## Pricing and Support

Plans cover scenario simulations, evidence packets, report exports, saved predictions, and team-oriented review support.
